# Debounce and throttle

A browser demonstration of immediate, debounced, and throttled input updates.

Start the Vite development server from the repository root:

```bash
npm run dev --workspace=@typescript-studies/debounce-throttle
```

The HTML imports `src/main.ts` directly. Vite handles browser transpilation and reloading, while the workspace's `check` and `build` scripts run TypeScript separately for type safety.
