# Algorithms

Algorithms are reusable, reference-quality implementations rather than one-off challenge answers. Group them by domain, document their contract and complexity, and test important edge cases.

Create a standalone algorithm study with:

```bash
npm run new-algorithm -- "Algorithm Name"
```

Current implementations:

- [`concurrency/map-limit`](./concurrency/map-limit/README.md): map asynchronous work with bounded concurrency while preserving input order.
