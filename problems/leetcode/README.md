# LeetCode problems

Each problem keeps its solution and tests together:

```text
problems/leetcode/<problem-slug>/
├── <problem-slug>.ts
└── <problem-slug>.test.ts
```

Create a scaffold with:

```bash
npm run new-leetcode -- "Problem Name"
```
